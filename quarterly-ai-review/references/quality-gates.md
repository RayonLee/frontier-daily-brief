# 季度报告质量门禁

## 目录

- 数据与证据
- 引用与链接
- 字体与视觉
- 常见失败及修复
- 发布前最终清单

## 数据与证据

- [ ] 时间范围与本次任务一致；“全部存档”和“单一季度”没有混用。
- [ ] 文件数、文本数、筛选数、去重数、核心/背景数均可复算。
- [ ] 重复网页、PDF、摘要和版本已归并，内部档案编号未重排。
- [ ] 企业自报、智库主张和本报告判断明确分开。
- [ ] 每项独立判断有支持证据、边界或反证、可监测指标。
- [ ] 新季度结论来自新季度证据，历史结论只用于明确标注的比较。

## 引用与链接

- [ ] 正文首次引用顺序为 1、2、3……，不存在档案编号跳号。
- [ ] 同一来源重复引用沿用首次编号。
- [ ] 正文独立来源数 N 与参考资料条目数 N 相等。
- [ ] 正文引用出现次数 M 与内部映射一致；不得用 M 代替 N。
- [ ] 参考资料编号从［1］连续至［N］，无未引用条目。
- [ ] 完整报告和独立参考资料使用相同顺序与 URL 集合。
- [ ] 所有最终来源均为公开 HTTPS 链接；无 `file://`、本地路径和“本地存档”。
- [ ] 两份 PDF 均无“编列说明”。
- [ ] 正文引用可跳到参考条目，参考条目可跳到公开来源。

## 字体与视觉

- [ ] 大标题和一级标题为黑体加粗。
- [ ] 二级及更低级别标题为楷体加粗，目录中的同级标题一致。
- [ ] 正文为宋体，核心观点句和表格中的重点判断为宋体加粗。
- [ ] 英文和数字为 Times New Roman，粗体语境为 Times New Roman Bold。
- [ ] 字体已嵌入，换机查看不发生非预期替换。
- [ ] 全部页面已渲染成图并生成联系图，所有低内容页均已人工复核。
- [ ] 无乱码、粘连、空白页、孤页、遮挡、裁切、长链接越界或表格断裂。
- [ ] 最后一次修改后重新执行自动校验和视觉校验。

## 常见失败及修复

| 失败 | 原因 | 修复 |
|---|---|---|
| 参考资料出现［1］、［8］、［10］ | 把证据档案编号当成引用编号 | 按首次出现重新生成 1…N 映射，正文与文末同步替换 |
| 同一来源被重复列多次 | 把引用出现次数当成独立来源数 | 重复来源复用编号，文末只保留 N 条 |
| 文末仍有“本地存档” | 缺少公开 URL 或 PDF 元数据 | 查找并核对公开页面；本地路径仅留证据索引 |
| 认为本地存档等于资料下架 | 误解兜底标记 | 单独在线核查，不根据存档标记推断删除 |
| 核心观点句没有加粗 | 粗体被映射回常规字体 | 使用真实粗体或经过验证的文本安全方案，并重新渲染 |
| 加粗后文字粘连或乱码 | 不兼容的描边或字体子集处理 | 停用该方案，保留原始文字层并更换实现 |
| 最后一页只有一条参考资料 | 行距或条目间距过大 | 微调参考资料行距和间距，重新检查全稿 |
| 改了一份 PDF，另一份不一致 | 未共享引用映射 | 完整报告和独立版共用同一顺序与 URL 集合 |
| 校验通过但视觉异常 | 只做结构检查 | 渲染全部页面并人工检查联系图和重点页 |
| 新季度出现旧季度数字 | 复制上一季度模板内容 | 从当前语料重新计算所有指标和结论 |

## 发布前最终清单

1. 自动校验脚本返回通过。
2. 页数、字数、图表数、引用数均来自当前成品。
3. 完整报告与独立参考资料的编号和链接一致。
4. 公开仓库仅包含通用技能文件，无报告全文、数据、字体或生成物。
5. 扫描本机路径、用户信息、内部标识、密钥、Cookie、私有链接和 Git 暂存清单。
6. 提交说明只描述通用功能，不包含本地环境或未公开研究内容。
