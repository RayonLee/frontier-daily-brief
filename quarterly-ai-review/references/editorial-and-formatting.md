# 编辑、引用与排版契约

## 目录

- 研究与证据表达
- 引用编号与参考资料
- 公开链接规则
- 字体、加粗与页面
- 敏感信息与发布边界

## 研究与证据表达

### 报告不是逐篇摘要

每一章围绕一个机制问题组织，而非围绕机构或日期排列。至少回答：

1. 哪些可核对事实支持该机制？
2. 因果链与反馈回路是什么？
3. 瓶颈从何处迁移到何处？
4. 哪些条件会使判断反转？
5. 下一季度用什么指标检验？

独立观察采用统一卡片：`判断｜支持证据｜反证与边界｜监测指标`。避免把分析式写成经过验证的统一生产函数。

### 数量口径

分别报告：原始文件数、可检索文本数、初筛候选数、去重记录数、核心材料数、背景材料数、正文独立来源数、引用出现次数。不得混用“文件”“报告”“研究对象”“证据记录”和“引用来源”。

全部数量由当季度数据计算。不得复用历史季度的文件数、引用数、图数、表数、页数、字数或结论。

## 引用编号与参考资料

### 唯一规则

- 按正文**首次出现顺序**从［1］到［N］编号。
- 同一来源重复出现时沿用首次编号，不新增号码。
- 正文可出现 M 次引用，但文末只有 N 个独立来源，M ≥ N。
- 参考资料顺序与首次出现顺序一致，编号连续，无跳号。
- 正文、完整报告和独立参考资料共用同一映射。
- 内部档案编号只用于回查证据，不进入最终引用显示。

### 条目格式

中文报告统一采用 GB/T 7714—2015 顺序编码制：

```text
［N］机构或作者. 题名[EB/OL]. (发布日期)[引用日期]. https://...
［N］机构或作者. 报告题名[R/OL]. (发布日期)[引用日期]. https://...
```

- 日期不详时使用可核实元数据，不猜测精确日期。
- 机构缺失时优先从原文元数据或官方页面补齐；仍无法确认时按规范省略作者项，不虚构机构。
- 完整报告和独立参考资料均直接从“参考资料”标题进入条目，**不写编列说明**。
- 默认不在报告尾部保留附录；用户明确要求时再添加，且不得影响引用连续性。

## 公开链接规则

### 最终产物

- 每条参考资料至少保留一个可点击的公开 HTTPS 链接，优先发布方官方页面或正式论文页面。
- 链接文字保留完整 URL，允许跨行，不得超出页面。
- 正文引用链接到对应参考条目；参考条目链接到公开来源。
- 独立参考资料的 URL 集合与完整报告一致。

### 本地存档的含义

“本地存档”只表示整理时缺少可用公开 URL，或来源为 PDF 提取文本，**不表示网上资料已经删除**。最终参考资料不得用本地路径代替公开链接；本地路径仅保存在不公开的证据索引中。

补链流程：

1. 用准确题名、机构和日期查找官方页面。
2. 核对标题、作者、日期与正文是否对应同一材料；标题变化时按官方现标题校准并保留核对记录。
3. 官方站点暂时不可访问时，可用正式论文页或可信索引确认 URL，但不得声称已直接访问成功。
4. 无法可靠确认时保留在证据索引并说明未核验，不编造网址。

## 字体、加粗与页面

| 元素 | 中文要求 | 英文和数字 |
|---|---|---|
| 封面主标题、一级标题 | 黑体加粗 | Times New Roman Bold |
| 二级及更低级别标题 | 楷体加粗 | Times New Roman Bold |
| 正文 | 宋体 | Times New Roman |
| 核心观点句 | 宋体加粗 | Times New Roman Bold |
| 表格正文 | 宋体 | Times New Roman |
| 表头 | 黑体加粗 | Times New Roman Bold |
| 页眉页脚、目录页码 | 宋体或标题对应字体 | Times New Roman |

### 加粗实现纪律

- 优先使用有授权的真实粗体字体，并嵌入 PDF。
- 不得把粗体静默映射回常规字体。
- 缺少中文粗体时，使用经过目标阅读器验证的文本安全方案，保留可复制、可检索的原始文字层。
- 不以单纯描边作为默认方案；出现粘连、错字或乱码时立即停用并更换实现。
- 标题、目录标题、核心判断表中的观点句都纳入加粗检查。
- 字体文件不进公开仓库；公开技能只记录字体名称和获取/使用要求。

### 页面验收

- 目录、页码、正文引用与参考条目链接有效。
- 长 URL 正常换行，表格无遮挡，图像清晰，中文字体不缺字。
- 无空白页、无仅一条参考资料的孤页、无孤立标题、无超出边距内容。
- 改变字体或编号后重新计算页数并重新渲染全部页面，不沿用旧页数和旧校验结果。

## 敏感信息与发布边界

只发布通用流程、模板和脚本。禁止提交：本机绝对路径、用户名、`file://` 地址、内部会话或运行环境标识、凭据、原始材料全文、证据索引、个人数据、字体二进制及未获授权的生成报告。

公开示例使用 `<WORKSPACE>`、`<RAW_DIR_A>`、`<RAW_DIR_B>`、`<OUTPUT_DIR>`、`<YYYY_Qn>` 等占位符。公开前同时检查文本内容和 Git 暂存文件清单。
